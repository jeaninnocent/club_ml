⚠️  POINTS IMPORTANTS

🔐 Sécurité:
   • Ne commitez JAMAIS .secret ou club.db
   • Utilisez les variables Vercel (pas de valeurs en dur)
   • Changez ADMIN_PASSWORD régulièrement
   • .gitignore protège déjà les secrets

💾 Base de données:
   • SQLite sur Vercel ne persiste PAS entre redéploiements
   • OK pour: développement, tests, démos
   • Pour production: voir DATABASE_MIGRATION.md

🔄 Mises à jour:
   • Chaque git push déclenche un redéploiement auto
   • git push origin main → Vercel redéploie en 2-3 min
