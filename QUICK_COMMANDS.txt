                    COMMANDES ESSENTIELLES VERCEL
═══════════════════════════════════════════════════════════════════════════

Utilisez ce fichier comme référence pour copier-coller les commandes!

───────────────────────────────────────────────────────────────────────────
1️⃣  VALIDATION LOCALE (avant de commencer)
───────────────────────────────────────────────────────────────────────────

Valider que Vercel est configuré:
    python test_vercel.py

Tester l'app localement:
    python app.py
    → Puis visitez http://localhost:5000

───────────────────────────────────────────────────────────────────────────
2️⃣  GÉNÉRER CREDENTIALS
───────────────────────────────────────────────────────────────────────────

Générer un mot de passe fort et une clé secrète:
    python generate_credentials.py

Alternative (si vous préférez faire manuellement):
    python -c "import secrets; print(secrets.token_hex(32))"
    → Copie la valeur pour SECRET_KEY

───────────────────────────────────────────────────────────────────────────
3️⃣  INITIALISER GIT
───────────────────────────────────────────────────────────────────────────

Initialiser le repo:
    git init

Ajouter tous les fichiers (sauf ceux dans .gitignore):
    git add .

Vérifier que les secrets NE sont pas ajoutés:
    git status
    → .secret et club.db ne doivent PAS apparaître

Faire le commit initial:
    git commit -m "Initial commit - Club ML Vercel deployment"

───────────────────────────────────────────────────────────────────────────
4️⃣  CONNECTER À GITHUB
───────────────────────────────────────────────────────────────────────────

Créer un repo sur GitHub:
    1. Allez sur https://github.com/new
    2. Remplissez "club-ml-plateforme"
    3. Cliquez "Create repository"

Ajouter le remote:
    git remote add origin https://github.com/VOTRE_USERNAME/club-ml-plateforme.git

Renommer la branche main (si nécessaire):
    git branch -M main

Pousser le code:
    git push -u origin main

───────────────────────────────────────────────────────────────────────────
5️⃣  DÉPLOYER SUR VERCEL (via interface web)
───────────────────────────────────────────────────────────────────────────

1. Allez sur:
    https://vercel.com/new

2. Connectez-vous avec GitHub

3. Sélectionnez votre repo "club-ml-plateforme"

4. Cliquez "Import"

5. Configurez les variables d'environnement:
    Settings → Environment Variables
    
    Ajoutez:
    ADMIN_USER = admin
    ADMIN_PASSWORD = (de step 2)
    SECRET_KEY = (de step 2)
    DB_PATH = /tmp/club.db

6. Cliquez "Deploy"

7. Attendez 2-3 minutes → ✅ C'est fini!

───────────────────────────────────────────────────────────────────────────
6️⃣  VÉRIFIER LE DÉPLOIEMENT
───────────────────────────────────────────────────────────────────────────

L'URL sera visible dans le dashboard Vercel:
    https://votre-projet-nom.vercel.app

Tester login apprenant:
    https://votre-projet-nom.vercel.app/login
    Username: admin
    Password: (celui que vous avez généré)

Tester login admin:
    https://votre-projet-nom.vercel.app/admin/login
    Username: admin
    Password: (celui que vous avez généré)

───────────────────────────────────────────────────────────────────────────
7️⃣  FUTURES MISES À JOUR (c'est simple!)
───────────────────────────────────────────────────────────────────────────

Quand vous modifiez le code:
    git add .
    git commit -m "Description des changements"
    git push origin main

Vercel redéploiera AUTOMATIQUEMENT en 2-3 minutes.
Pas besoin de faire quoi que ce soit!

───────────────────────────────────────────────────────────────────────────
8️⃣  ALTERNATIVE: Déployer via Vercel CLI (si vous avez Node.js)
───────────────────────────────────────────────────────────────────────────

Installer Vercel CLI (optionnel):
    npm install -g vercel

Déployer:
    vercel

Puis suivez les prompts.

───────────────────────────────────────────────────────────────────────────
❓ COMMANDES DE DÉPANNAGE
───────────────────────────────────────────────────────────────────────────

Voir le statut Git:
    git status

Voir les commits:
    git log --oneline

Voir les remotes configurés:
    git remote -v

Annuler les changements non committés:
    git reset --hard

Voir les variables Vercel (depuis la CLI):
    vercel env ls

Voir les logs Vercel (depuis la CLI):
    vercel logs
    (Nécessite Vercel CLI installé)

───────────────────────────────────────────────────────────────────────────
🔐 COMMANDES SÉCURITÉ
───────────────────────────────────────────────────────────────────────────

Vérifier que les secrets NE sont pas dans Git:
    git ls-files | grep -E "(\.secret|club\.db|\.env)"
    → Ne doit rien afficher

Voir ce qui sera committé:
    git diff --cached

Ajouter les secrets à .gitignore si oubliés:
    echo ".secret" >> .gitignore
    echo "club.db" >> .gitignore

Ajouter les fichiers temporaires si oubliés:
    echo "__pycache__/" >> .gitignore
    echo "*.pyc" >> .gitignore

───────────────────────────────────────────────────────────────────────────
📊 COMMANDES D'INFO UTILES
───────────────────────────────────────────────────────────────────────────

Taille des fichiers:
    du -sh *

Voir la structure du projet:
    tree -L 2 -I 'env|__pycache__|*.pyc'
    (Ou: dir /s /b si tree n'est pas disponible)

Voir la taille de la BD:
    ls -lh club.db
